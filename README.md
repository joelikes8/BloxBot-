# BloxBot

A Discord bot for Roblox order management, built with Python using discord.py.

## Features

- User profile management with Roblox account linking
- Order processing for Roblox bot development
- Payment tracking and verification
- Admin tools for order management
- Notification system
- Web dashboard integration

## Technology

- Python with discord.py for bot functionality
- Flask for web dashboard
- PostgreSQL database for data storage
- SQLAlchemy ORM

## Project Structure

- `/cogs`: Discord bot command modules
- `/database`: Database models and connection utilities  
- `/utils`: Helper functions and utilities
- `/app.py`: Flask web application
- `/main.py`: Discord bot entry point
